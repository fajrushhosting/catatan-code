Pengaturan Supabase

Agar sinkronisasi ke cloud berfungsi, jalankan kode SQL ini di menu SQL Editor pada dashboard Supabase Anda: 

CREATE TABLE public.coding_notes (
    id text primary key,
    content text,
    language text,
    updated_at timestamp with time zone default now()
);

-- Matikan RLS agar bisa simpan tanpa login
ALTER TABLE public.coding_notes DISABLE ROW LEVEL SECURITY;

Jangan khawatir, jika tabel belum dibuat, kode tetap aman tersimpan otomatis di penyimpanan lokal (perangkat) Anda.
